# 🚀 Splito Version 1.0.0 — Official Release Notes

**Release Version**: `v1.0.0`  
**Release Date**: 2026-08-01  
**Status**: 🟢 **OFFICIAL PRODUCTION RELEASE**  

---

## 🌟 Highlights

- **Complete Group Expense Management**: Equal, percentage, exact, and share-based expense splitting.
- **Neo-Clay Design System**: Premium 3D surface elevations (`shadow-neo-1` through `shadow-neo-4`) with dark mode support.
- **Offline Mutation Queue & PWA**: IndexedDB-backed mutation queue replay when connectivity recovers.
- **OpenAPI Code Generation**: Type-safe DTOs and API clients generated directly from `openapi.json`.
- **Enterprise Reporting & Export**: Export financial data to CSV, JSON, and Print formats.
- **Real-Time Workspace Personalization**: Customizable accent colors, display densities, and motion settings.

---

## 🏛️ Architecture & Platform Features

- **Next.js 16 App Router & React 19**: Server Components and Client Boundaries.
- **Repository Pattern**: Strict isolation between UI components and HTTP API endpoints.
- **Single-Flight Refresh Queue**: Prevents request storms on `401 Unauthorized` token expiry.
- **WCAG 2.2 AA Accessibility**: Full keyboard navigation, screen reader support, and focus visibility.
